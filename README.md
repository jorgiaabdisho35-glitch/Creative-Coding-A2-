## General info
This project uses TunePad to construct a mood-responsive music prototype in Python. it investigates how various emotional states might be reflected in music. This project aims to investigate the connection between music, feelings, and code while showcasing the creative potential of programming. 
	
## Technologies
Project is created with:
python,
tunepad,
loops and functions,
python conditionals
